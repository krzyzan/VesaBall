# VesaBall

VesaBall is a Breakout/Arkanoid-style block-breaking game for Windows, written in C++ with DirectX 8 (Direct3D 8 + DirectInput 8). It features mouse-controlled paddle play, 50 built-in levels, a variety of bonus power-ups, and a built-in level editor.

## Features

- **Classic brick-breaking gameplay** — bounce the ball off a mouse-controlled paddle to clear boards of bricks.
- **50 levels** included under `lev/` (`00.lev`–`49.lev`).
- **Bonus power-ups**, including expanding/shrinking paddle and ball, extra life, fireball, multi-ball split, exploding bricks, level warp, thru-brick, and more (see `gfx/Bonus_*.png`).
- **Level editor** (`CGameEditor`), accessible from the main menu, for creating or modifying levels.
- **Configurable resolution** via `cfg/res.cfg`.

## Requirements

- Windows (the game targets the Win32 API and DirectX 8).
- [DirectX 8](https://en.wikipedia.org/wiki/DirectX) runtime installed (`d3d8.dll`, `d3dx8`, `dinput8`).
- A toolchain to build from source (see below) — the game is not distributed prebuilt in this repository.

## Building from source

The project predates modern build tooling and ships two legacy build options. Either requires the **DirectX 8 SDK** headers and import libraries (`d3d8.h`/`d3d8.lib`, `d3dx8.h`/`d3dx8.lib`, `dinput.h`/`dinput8.lib`/`dxguid.lib`, `dxerr8.h`).

### Option A: Visual Studio (`VesaBall.sln` / `VesaBall.vcproj`)

1. Install the DirectX 8 SDK and point your compiler's include/library paths at it.
2. Open `VesaBall.sln` in Visual Studio (the project file is in the old VS 2003-era format; newer Visual Studio versions will offer to upgrade it).
3. Build the `Release` or `Debug` configuration for `Win32`.
4. The resulting `VesaBall.exe` needs the `cfg/`, `gfx/`, and `lev/` folders alongside it at runtime.

### Option B: Dev-C++ / MinGW (`VesaBall.dev` / `Makefile.win`)

The `Makefile.win` was generated by Dev-C++ 4.9.9 and hardcodes paths like `C:/Dev-Cpp/include` and `C:/Dev-Cpp/lib`. To build with it:

1. Install [Dev-C++](https://www.bloodshed.net/) (or a compatible old MinGW/g++ toolchain) at `C:/Dev-Cpp`, or edit `Makefile.win` to point `INCS`, `CXXINCS`, and `LIBS` at your own MinGW and DirectX 8 SDK paths.
2. Ensure `libdinput8.a`, `libdxguid.a`, `libd3dx8.a`, and `libd3d8.a` are available in your MinGW lib directory (these are DirectX 8 import libraries built for MinGW).
3. From a Windows shell:
   ```
   mingw32-make -f Makefile.win
   ```
4. Alternatively, open `VesaBall.dev` directly in Dev-C++ and build from there.

## Running

After building, run `VesaBall.exe` from the repository root (or copy it next to the `cfg/`, `gfx/`, and `lev/` directories) so it can find its assets and `cfg/res.cfg`.

## Controls

- **Mouse move** — move the paddle.
- **Left mouse button** — launch a caught ball.
- **P** / **Pause** — pause the game.
- **Sys Rq** — toggle cheat mode.
- With cheats enabled: **Space** clears all bricks, **B** spawns/cycles bonus power-ups, holding **right mouse button** slows the game down.

## Project layout

| Path | Contents |
|---|---|
| `*.cpp` / `*.h` | Game source (rendering, game engine, sprites, bricks, paddle, ball, bonuses, menu, editor). |
| `cfg/res.cfg` | Screen resolution (width and height, one per line). |
| `gfx/` | Sprite textures (bricks, paddle, ball, bonuses, UI). |
| `lev/` | Level data files (`00.lev`–`49.lev`). |
| `VesaBall.sln`, `VesaBall.vcproj` | Visual Studio project files. |
| `VesaBall.dev`, `Makefile.win` | Dev-C++ / MinGW project files. |
| `Doxyfile` | Doxygen configuration for generating API documentation from the source comments. |

## Documentation
